Profil & contact

Photo du photographe (portrait recommandé) — cliquez ou glissez-déposez

Affichée dans la section Contact du site, toujours recadrée automatiquement en portrait — n'importe quelle photo fonctionne, pas besoin de la recadrer vous-même avant l'envoi.

Paiement — Mobile Money / carte (KKiaPay)

Créez un compte gratuit sur kkiapay.me, récupérez votre clé publique (menu Développeurs → Clés API) et collez-la ci-dessous. Copiez ensuite l'URL et le secret de webhook affichés en bas dans votre tableau de bord KKiaPay (menu Webhook), pour que les paiements soient confirmés automatiquement.

Paiement — Mobile Money / carte (GeniusPay) En préparation

Postulez sur onboarding.geniuspay.ci pour obtenir un compte marchand. Une fois validé, récupérez votre clé API et votre secret API dans votre tableau de bord GeniusPay et enregistrez-les ci-dessous. Le paiement effectif via GeniusPay n'est pas encore actif sur ce site — la vérification sécurisée des notifications de paiement (webhook) sera ajoutée dès que la documentation officielle sera disponible. Enregistrer vos clés ici les met simplement de côté, prêtes pour cette prochaine étape.

Assistant IA — okim.box

Un assistant conversationnel affiché sur le site public, qui répond aux questions des visiteurs à partir des informations réelles et actuelles du site (services, boutique, formations, logiciels) — jamais d'information inventée. Nécessite une clé API console.anthropic.com. Quand l'assistant ne peut pas répondre (réclamation, remboursement, question hors périmètre), la conversation est automatiquement transférée dans vos Messages.

Notifications automatiques

Recevez un e-mail automatique à chaque commande payée, nouveau message ou inscription à une formation — sans avoir à surveiller le tableau de bord. Envoyé à l'adresse renseignée dans « Profil & contact ». Le client reçoit lui aussi automatiquement ses liens de téléchargement après paiement.

Pour être alerté autrement que par e-mail (WhatsApp, SMS, Telegram...), branchez ce webhook à un outil d'automatisation sans code comme Make, Zapier ou n8n : chaque événement (commande payée, message, inscription) lui sera envoyé, à vous de choisir où il relaie l'alerte.

Sécurité

Le nom ci-dessous sert à réinitialiser votre mot de passe si vous le perdez (via « Mot de passe oublié » sur la page de connexion). Choisissez-en un que vous retiendrez facilement.

Comptes administrateurs

Vous êtes le propriétaire : vous seul pouvez accéder à cette page Paramètres et voir l'identifiant interne des comptes clients. Deux types de comptes employé possibles : Admin (accès complet, sauf Paramètres/Comptes) ou Secrétaire (Contenu, Boutique et Clients uniquement, sans pouvoir rien supprimer).
